# Circle Flags used by the app, one per line, fetched into public/flags/
# by ./scripts/build-flags.py.
#
# Source: https://github.com/HatScripts/circle-flags (MIT). Vendored rather
# than hotlinked from their CDN for the same reasons as the fonts: no
# third-party request on every page load, no dependency on someone else's
# uptime, and the set is pinned so a redesign upstream cannot change our UI.
#
# Two namespaces, and the difference matters:
#
#   language/<code>   A flag for a LANGUAGE. Use these for languages.
#   <country>         A flag for a COUNTRY. Use these for dialling codes.
#
# A language is not a country. Arabic is spoken across two dozen states, so
# showing Saudi Arabia's flag next to "Arabic" tells a Lebanese or Egyptian
# speaker their language belongs to somewhere else. Circle Flags ships
# purpose-made language flags for exactly this; where one exists, it wins.
#
# Note: many files under language/ are git symlinks to a country flag. The
# fetcher resolves them - see build-flags.py.
