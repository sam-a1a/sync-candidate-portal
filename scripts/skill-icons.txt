# Fetched into public/skill-icons/ by ./scripts/build-skill-icons.py, which
# also writes the lookup in src/features/profile/skill-icons.generated.ts.
#
# Simple Icons (https://simpleicons.org) rather than thesvg.org: it is CC0, so
# there is no licence question, and every icon is a single path on a 24x24
# viewBox with no fill, which is what lets it be tinted with the brand's own
# colour from the data file.
#
# MOST SKILLS WILL NEVER APPEAR HERE, and that is fine. "Humanitarian
# logistics" and "Monitoring & evaluation" have no logo and never will; KoBo
# Toolbox, ODK, DHIS2, SPSS and Stata exist in the world but not in Simple
# Icons. A row where one in eight has a mark looks broken, so the rule is:
# show an icon only where one exists, reserve no space for the rest, and never
# substitute a placeholder.
#
# Names are matched case-insensitively against the skill text.
